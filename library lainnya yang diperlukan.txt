@tanstack/react-query (Otak Data / Server State)

Fungsi: Menangani caching, infinite scroll (useInfiniteQuery), optimistic updates (UI berubah instan saat save), dan auto-refetch.

Kenapa wajib? Ini yang akan menggantikan seluruh useEffect berantakan di page.tsx Anda.

2. zustand (Otak UI / Global Client State)

Fungsi: Menyimpan state yang tidak ada hubungannya dengan database, tapi butuh diakses lintas komponen.

Contoh: Status Sidebar (terbuka/tertutup), Theme (Dark/Light mode), atau menyimpan Draft sementara dari tabel sebelum dikirim ke Supabase. Jauh lebih ringan dan minim boilerplate dibanding Redux atau React Context.

3. react-hook-form + zod (Otak Validasi & Form)

Fungsi: Saat nanti Anda membuat Modal "Add Row" atau "Edit Row" yang kompleks, dua library ini adalah standar industri.

Kenapa wajib? react-hook-form membuat form tidak lag saat diketik, dan zod memastikan data yang masuk (misal: harga harus angka, email harus valid) benar-benar valid sebelum dikirim ke Supabase.

4. date-fns atau dayjs (Otak Waktu)

Fungsi: Memanipulasi data timestamptz dari Supabase.

Kenapa wajib? Karena Javascript Date bawaan sangat menyebalkan. Ini mempermudah Anda memformat "Last Updated: 2 hours ago" atau "15 Jan 2024".

5. nuqs (Opsional tapi Super Pro: URL State Management)

Fungsi: Menyimpan state Filter dan Sorting langsung ke URL (misal: ?kitab=Matius&sort=price_desc).

Kenapa wajib? Supaya kalau user me- refresh halaman (F5) atau membagikan link halaman itu ke staf lain, tabelnya akan langsung terbuka dengan filter "Matius" yang sudah aktif, tidak kembali ke default.
