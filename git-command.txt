# Langkah 1: Ganti "Kunci Akses" (Hapus Cache Autentikasi Windows)
Agar Git meminta Anda login ulang dengan akun yang baru, kita harus menghapus ingatan Windows:
- Buka menu Start Windows di laptop Anda.
- Ketik Credential Manager (atau Pengelola Kredensial) dan buka aplikasinya.
- Pilih tab Windows Credentials (Kredensial Windows).
- Scroll ke bawah ke bagian Generic Credentials, lalu cari daftar yang berawalan git:https://github.com.
- Klik baris tersebut untuk membukanya, lalu klik Remove (Hapus).

# Langkah 2 : Ganti Identitas Commit (Nama & Email)
# Jalankan dua perintah ini di terminal VS Code Anda saat ini (ganti bagian dalam tanda kutip dengan nama dan email akun GitHub untuk website ini):

git config user.name "ceritabahasadaerah"
git config user.email "ceritabahasadaerah@gmail.com"

(Catatan: Perintah di atas sengaja tidak memakai --global agar perubahan ini hanya berlaku secara lokal di folder ceritabahasadaerah saja).

# Langkah 3: Tes Push Ulang
Sekarang, sistem sudah bersih dari akun lama untuk project ini. Silakan lakukan proses commit dan push untuk update Cron Job kita tadi:

git add .
git commit -m "feat: update cron job sync google sheets"
git push origin main
Karena cache password sudah kita hapus di Langkah 2, saat Anda menekan Enter pada perintah git push,
sistem akan otomatis memunculkan jendela pop-up kecil (atau membuka browser) yang meminta Anda untuk Sign in to GitHub.
